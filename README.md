# 名探偵コナン エピソード索引（非公式）

アニメ『名探偵コナン』の全エピソードに、登場人物や話の性質のラベルを付けて
**「次に観る回を選ぶ」ために絞り込めるようにした、個人的な索引**です。

**個人が作成した非公式のファンサイトです。**
小学館・読売テレビ・トムス・エンタテインメントとは一切関係ありません。

## 広く使ってもらうことは意図していません

自分が iPhone から使うために公開しているだけで、宣伝もしていません。
`robots.txt` と `noindex` で検索エンジンからの登録を拒否しています。

## 何が入っているか

このリポジトリは**配信専用**です。生成元のコードとデータは別のリポジトリにあり、
そちらは公開していません。

| ファイル | 内容 |
|---|---|
| `index.html` | 検索UI（外部ライブラリを使わない素の HTML / CSS / JS） |
| `data.json` | 作品ごとの事実データと、付与したラベル |
| `robots.txt` | 検索エンジンからの登録拒否 |

## データについて

**事実データ**（話数・邦題・英題・放送日・原作対応巻・原作回かどうか・形式・登場人物）は
下記の出典から取得しています。

- [Detective Conan Wiki](https://www.detectiveconanworld.com/wiki/) — CC BY-SA 3.0
- [日本語版ウィキペディア「名探偵コナンのアニメエピソード一覧」](https://ja.wikipedia.org/wiki/名探偵コナンのアニメエピソード一覧) — CC BY-SA 4.0

**ラベル**（黒の組織の関与度・事件の種類・舞台・トリック種別など）は
上記のあらすじを読んで作成者が分類したもので、**公式のものではありません。**
誤りが含まれている可能性があります。

### 含まれていないもの

- **あらすじ本文・事件の真相** — 出典の文章をそのまま再配布しないため
- **判定根拠の引用** — 同上。加えて、未視聴の回を探す用途でネタバレになるため
- **画像** — 権利が別のため一切使用していません

## 権利について

`index.html` と `data.json` のラベルは、このサイトの作成者が書いたものです。
事実データそのものには著作権が及びません。

作品名・キャラクター名・その他の固有名詞に関する権利は、それぞれの権利者に帰属します。
`名探偵コナン` は登録商標です。**公式サイトではありません。**
